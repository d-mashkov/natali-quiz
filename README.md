# Квиз Натали

Семейный квиз: 7 раундов, 69 вопросов. Все изображения, звуковые записи и оформление находятся в проекте.

## Запуск без интернета

1. Скачайте проект и распакуйте его в папку на ноутбуке.
2. Откройте `Natali-Quiz.html` в Chrome.
3. Изображения и аудио встроены в файл. Интернет и установка программ не нужны.
4. Проверьте звук до подключения проектора. Кнопка «Весь экран» скрывает меню.

## Файлы

- `Natali-Quiz.html` — готовый автономный квиз.
- `web/` — исходники интерфейса и отдельные изображения и аудиофайлы.
- `print/` — бланки команд А5 и ключ для проверяющего.
- `build_offline.py` — сборка автономного HTML командой `python3 build_offline.py` после изменения исходников.

После каждого раунда соберите бланки, затем откройте разбор ответов. В раунде «Что выберет Наталья?» ответы определяются во время игры.

Фотографии, аудио и ответы предназначены для семейного мероприятия.
