# Квиз Натали

7 раундов, 69 вопросов.

## Запуск без интернета
Скачайте и откройте Natali-Quiz.html в Chrome. Фото, оформление и аудио встроены в файл. Перед мероприятием проверьте звук.

## Исходники
Папка web содержит интерфейс, фотографии и аудио. После правок запустите python3 build_offline.py для пересборки автономного файла.

В раунде «Что выберет Наталья?» ответы определяются во время игры.
